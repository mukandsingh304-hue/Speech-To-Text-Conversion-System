Why Word Error Rate (WER) in this BCA Project?
Building or training an enterprise speech recognition neural network requires hundreds of gigabytes of audio datasets and heavy GPU training clusters. In this project, we utilize a pretrained ASR model for inference and implement the Word Error Rate (WER) metric using the Levenshtein Dynamic Programming Algorithm. This mathematically evaluates how accurately the speech was recognized compared against the known reference speech transcript.

System Architecture & Technical Design
1. System Workflow & Data Pipeline
Speech-to-Text (STT) Flow:
[Microphone / WAV File]
  ↓ (16-bit PCM Audio Validation)
[Flask POST /api/speech-to-text]
  ↓ (Acoustic Feature Extraction)
[Google Speech Recognition Cloud Engine]
  ↓ (Language Model Decoding)
[Recognized UTF-8 Text Output]

Text-to-Speech (TTS) Flow:
[User Text Input]
  ↓ (Text Normalization & Tokenization)
[Flask POST /api/text-to-speech]
  ↓ (Phoneme to Acoustic Waveform)
[pyttsx3 Offline Windows SAPI5 Engine]
  ↓ (Base64 WAV Stream)
[Browser HTML5 Audio Player / WAV Download]
2. Offline vs. Online Capabilities
Module Engine / Library Internet Required? Offline Fallback?
Speech-to-Text SpeechRecognition (Google ASR) Yes (Online) Vosk / PocketSphinx can be plugged in for full offline
Text-to-Speech pyttsx3 (Windows SAPI5) No (100% Offline) Native Windows built-in voices
Fallback TTS Web SpeechSynthesis API No (Client Offline) Executes directly inside browser
WER Evaluator Levenshtein DP Algorithm No (100% Offline) Pure Python algorithmic computation

Answer: WER is the standard metric for measuring the performance of an Automatic Speech Recognition (ASR) system. It is calculated as: WER = (S + D + I) / N, where S is the number of substitutions, D is deletions, I is insertions, and N is the total number of words in the ground truth reference text. It is computed via the Levenshtein dynamic programming algorithm at the word level.
